# Claude Agent SDK 与 PilotDeck 能力差距矩阵

原生语义状态以 `20b8826` 已提交快照为准；本次 worktree 额外实现的 `@pilotdeck/sdk` alpha 仅通过 Gateway adapter 包装这些语义，不纳入原目标 worktree 的其他未提交改动。

## 总体判断

1. **核心执行语义**：PilotDeck 与 Claude Agent SDK 在“模型 → 工具 → 结果 → 继续/终止”的 Agent Loop 上基本同类，可判为等价或部分等价。
2. **控制平面**：PilotDeck 更强调宿主拥有 session/turn/run/operation、Gateway、权限和持久化；Claude 更强调 SDK `Options` 和 `query()` 的直接可编程性。
3. **扩展平面**：PilotDeck 已具备 Hooks、MCP、Plugins、Skills 和 Subagents 的内部实现；本次 alpha 已提供 query、session、permission、MCP、native lifecycle hooks 与 typed message 入口。SDK callback 通过可达 HTTP endpoint 桥接，Claude 独有 hook event 与 `AgentDefinition` 的完整远程 callback 面仍弱于 Claude Agent SDK。
4. **产品平面**：Gateway、多通道、cron、always-on、项目/工作区注册和 sidecar protocol 是 PilotDeck 专有或较低层能力，不能拿 Claude SDK 的缺失当作 PilotDeck 缺陷。
