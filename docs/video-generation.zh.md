# 视频生成

视频生成是独立的可选能力，默认关闭。在「设置 → 视频生成」填写 API 密钥、Videos API 基础地址和模型名称。如果服务要求模型专属参数，可展开「模型参数（可选）」填写 JSON 默认值，例如 MiniMax-H3 的 `{"task":"t2va","aspect_ratio":"16:9"}`。关闭后，新一轮模型请求中不包含 `generate_video`、`save_generated_video`；已经生成的视频仍可播放和下载。

## 接口和执行

本版使用 OpenAI 兼容 Videos API：以 multipart 表单提交 `POST /v1/videos`，查询 `GET /v1/videos/{id}`，完成后下载 `GET /v1/videos/{id}/content`。模型名称不限制为 OpenAI 官方模型。中转站需要提供这些路由并支持所选模型；仅在模型列表中添加名称不足以完成接入。

整个提交、查询、下载过程在一次工具调用内等待完成，没有新增后台任务、跨轮唤醒或额外的用户调度流程。总超时为 20 分钟；取消和超时会尝试删除远端任务，远端服务是否立即停止取决于其实现。生成 POST 不自动重试，以免产生重复视频。

`generate_video` 接收提示词、用途、可选时长（默认 5 秒）、尺寸，以及服务支持时可用的采样步数和随机种子。第一版提供文生视频。`save_generated_video` 根据已有视频 ID 导出文件，不会重新生成；输出路径必须位于允许的工作目录，后缀为 `.mp4`，且不会覆盖已有文件。

## 展示和存储

模型必须明确指定 `purpose`：

- `deliverable`：视频本身就是用户需要的成果。生成时展示动画占位，完成后原地展示播放器；工具调用记录仍可在「已处理」内展开查看。
- `intermediate`：用于网站、演示文稿等工作的素材。随工具执行过程折叠，展开详情可播放。

失败调用按普通工具错误折叠，不留下大尺寸失败卡片。播放器支持播放、进度拖动、全屏和悬停下载；浏览器不支持编码时保留下载入口。

视频流式写入 `PILOT_HOME/generated-videos` 下的持久会话附件，单个附件上限 512 MiB。默认不向项目写文件。明确要求保存或项目需要视频资产时，才设置 `output_path` 或调用保存工具。

附件按会话隔离。父任务和子任务通过受信运行时显式继承原始文件；分叉会话按分叉点继承保留历史中使用的附件，并重绑定历史元数据。继承后不依赖源会话文件继续存在。最终视频也会通过标准文件附件事件交给 IM 通道；中间素材和单纯保存操作不重复投递。

项目文件树及聊天中的文件入口共用视频预览，MP4、WebM、MOV 等扩展名不会作为文本加载或编辑。项目视频与会话视频均使用带鉴权的媒体 URL 和 HTTP Range，避免将整个大文件读入浏览器内存。播放能力取决于浏览器编码支持，H.264/AAC MP4 通常兼容性较好。
