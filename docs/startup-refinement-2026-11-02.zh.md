# 启动连续性、原生安装器和测试包

基于合并后的 `main`，本轮按反馈恢复 Windows 安装器的原生页面与绿色进度条，保留卸载时默认不清理个人数据的确认框。没有再次调整配置格式或目录。

## 界面修正

- 删除自定义安装欢迎页和完成页，恢复 electron-builder/NSIS 原生页面、字体、布局及全尺寸绿色进度条。保留累积进度、取消保护、事务替换和回滚机制。
- 安装完成页使用原生 MUI 的两个默认勾选项：**启动 PilotDeck**、**创建桌面快捷方式**。桌面快捷方式在点击完成后按选择创建，包含程序图标和 AppUserModelID；取消创建不删除已有快捷方式。正常卸载仍移除程序自己的快捷方式，更新时保留现有快捷方式。
- 安装、卸载、失败提示和完成页勾选项提供英文与简体中文。修复了若干安装阶段仍显示英文的提示。进度条使用系统控件，外观还受 Windows 主题影响。[NSIS 原生进度条设置](https://nsis.sourceforge.io/Reference/InstProgressFlags)
- 系统运行日志下拉框复用高级设置输入框的规则。实际网页测得：同为 40 px 高、14 px 字号、9 px 圆角、左右 13 px 内边距。
- 设置与启动错误页均使用“下载运行日志 / Download runtime logs”，同时本地化桌面另存为标题和日志文件类型。

## 启动连续性

闪烁的重要来源是原生加载 HTML、网页首屏、React 加载组件接替时销毁并重建启动内容，同时重复播放淡入动画。

网页首屏现在置于 React 根节点之外，直到工作区准备好才统一完成并淡出。React 的认证、Gateway、完成阶段更新同一组 DOM 节点，不再移除品牌和进度条。加载阶段不重复淡入，高光使用启动时间偏移保持连续。非常快的启动只保留 200 ms 的最短呈现，之后完成进度并淡出；减少动态效果设置仍有效。

桌面移除每次开窗都清空整个 HTTP 缓存的操作。静态资源采用内容哈希，HTML 仍重新校验。桌面收到 Gateway 就绪事件后立即更新状态，避免等待下一次 500 ms HTTP 轮询。

## 启动调度与基准

新增轻量的受监督入口，先加载现有环境和配置校验，再通知监督进程启动 Gateway，同时继续初始化 Web 路由。桌面和独立 Web 监督器均使用该入口；旧运行时目录没有此文件时，继续使用旧入口。

提前启动仍使用现有完整的模型配置判定，空模型池和无效配置不会启动 Gateway。Web 启动失败会停止提前启动的 Gateway。停止前先解除当前进程引用，避免 readiness 的拒绝回调覆盖原始 Web 错误。图像处理库改为首次执行图像操作时加载。

同机隔离配置、不调用真实模型的三次样本：

| 模式 | 新临时配置：服务及项目接口可用 | 已有配置样本 1 | 已有配置样本 2 |
| --- | --- | --- | --- |
| 相同代码，强制串行 | 9.650 s | 6.274 s | 7.297 s |
| 重叠启动 | 7.623 s | 4.046 s | 3.889 s |

已有配置样本的中位数从 6.786 s 降至 3.968 s，约降低 41%。这是本机小样本，测量服务及项目接口可用时间，不等同于完整客户端首次打开耗时。

复现：`node scripts/benchmark-startup.mjs --samples 3`；加 `--serial` 可在同一代码上对照串行方式。

- UI 启动状态、同一 DOM 节点接管、快速完成、错误原因、下载日志、原生就绪事件及日志设置等相关用例：46 项通过。
- Web 监督器、运行协调、模型配置判定与图像测试接口：50 项通过（其中图像测试接口也包含在上一组）。
- Node 桌面加载 HTML、清理边界及 Linux 卸载控制：12 项通过。
- NSIS 安装、卸载脚本编译通过；安装完成页两项回调和中英文资源编译通过。
- 实际 `.lnk` 创建测试通过：目标、图标和 AppUserModelID 正确，覆盖中文路径，未写入用户真实桌面。
- 解压、替换、回滚、锁定重试、损坏归档、Unicode 路径和组件保留的安装事务测试通过。
- TypeScript 检查及 Vite 生产构建通过；构建仍有既有的大 chunk 提示。
- 图像相关核心回归为 20 项通过、4 项失败；四项与此前独立 `main` 的 Windows 基线相同，涉及监听权限、符号链接和路径断言，本轮未修改这些范围。

实际客户端的 Web 缺文件故障已确认显示 `PD_RESOURCE_NOT_FOUND`、中文原因、日志路径、重启及下载按钮；没有被提前停止 Gateway 的次要错误覆盖。无效 YAML 测试的 Web 服务可启动，未启动 Gateway。慢启动副本进入了工作区。

用户在后续慢启动界面检查时按 Esc 停止了 Computer Use，之后未继续操作窗口。因此最后的逐阶段动画走查、带新勾选框的最终安装包界面走查仍需人工确认。没有进行 macOS/Linux 实机验证。
